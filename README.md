# 『DIRECT』 戦略ボードゲーム (Web App)

ボードゲーム「コリドール (Quoridor)」をベースに、長さの異なる3種類の壁と、戦局を大きく覆す「アクションカード」を追加した完全情報型の戦略ボードゲーム **『DIRECT』** のWebアプリケーションです。

---

## 🎮 特徴

- **完全情報・運要素ゼロ**: ダイスや山札のランダム性なし。お互いの手札・壁ストックを全て把握して競う本格頭脳戦。
- **3種類の壁長さ**: 1マス・2マス・3マスの壁を戦略的に使い分ける思考性。
- **5枚のアクションカード**:
  - 【ジャンプ】: 壁を飛び越えて1マス移動
  - 【2マス移動】: 壁を迂回して2マス移動（L字移動可能）
  - 【壁2個設置】: 1ターンで壁を2枚連続設置
  - 【壁回収】: 盤面の壁（相手の壁含む）を取り除き自分のストックに回収
- **絶対ルール自動判定**: BFS（幅優先探索）により、どちらかのコマのゴール経路が完全封鎖される壁設置を自動禁止。
- **豊富な対戦モード**:
  - **ローカル2人対戦** (1台の画面で対戦)
  - **VS AI** (初級・中級・上級)
  - **オンライン対戦 (WebRTC / PeerJS)** (サーバーレス・P2Pリアルタイム通信)
- **演出・効果音**: Web Audio APIによるリッチなサウンド効果音・勝利ファンファーレ・紙吹雪演出。

## 🚀 Vercel へのデプロイ方法

### 方法 1: Vercel CLI (推奨・簡単)

1. Vercel CLI をインストール（未導入の場合）:
   ```bash
   npm install -g vercel
   ```

2. 本プロジェクトのディレクトリで `vercel` コマンドを実行:
   ```bash
   vercel
   ```

3. 画面の指示に従ってログインし、デプロイ完了！

### 方法 2: GitHub 連携 (1クリック自動デプロイ)

1. 本リポジトリを GitHub にプッシュします。
2. [Vercel Dashboard](https://vercel.com/new) にアクセスします。
3. リポジトリを選択し、`Deploy` をクリックします。
   *(Next.js が自動認識され、追加の環境変数設定なしで即時公開されます)*
